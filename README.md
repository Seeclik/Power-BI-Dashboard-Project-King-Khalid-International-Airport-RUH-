# Power-BI-Dashboard-Project-King-Khalid-International-Airport-RUH-
## 📌 Project Overview
This project presents a comprehensive dashboard analyzing flight operations at King Khalid International Airport (RUH) from March through October 10, 2025. Built using Power BI, the dashboard visualizes key metrics and patterns to support operational insights and decision-making.

## 📦 Dataset Source
The raw data utilized for this analysis and modeling comes from the following source:

 [Dataset](https://www.linkedin.com/in/mohammed-alsubaie-81a857187/)


 ## 🚀 Key Objectives & Insights

The analysis successfully addressed critical business questions and provided the following actionable insights:

| Focus Area | Key Finding |
| :--- | :--- |
| Flight Volume | Captured 11.6K flights between March–October 2025, averaging 55 flights per day. |
| Seasonality | Identified peak travel months in July and August, crucial for resource planning. |
| Airline Performance | **Saudi Arabian, flynas, and flyadeal** lead in daily flight contributions. |
| Destination Traffic | **Medina, Doha, and London** are the top destinations, with Medina reaching 3,298 flights. |
| Flight Reliability | Achieved **99.33%** departure rate, indicating high operational efficiency. |
| Time of Day Trends | **Night flights** dominate at 40.76%, followed by morning and evening. |
| Weekday Patterns | **Monday, and Friday** are the busiest days, while Tuesday shows the lowest activity. |
